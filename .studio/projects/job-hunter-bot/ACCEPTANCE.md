# Приёмка v1 — «Охотник за вакансиями» (G6)

Проверяет владелец в живом Telegram после запуска на сервере или локально. Каждый пункт: ✅ / ❌ + комментарий.

## Подготовка (один раз)

1. Создать бота у @BotFather, получить токен.
2. `cp .env.example .env`, заполнить `BOT_TOKEN`, `MASTER_KEY` (команда генерации в README), `POSTGRES_PASSWORD`.
3. `docker compose up -d --build` → `docker compose ps`: оба сервиса `healthy`.

## Известные ограничения v1

- hh.ru автоматически — только с токеном приложения (`HH_TOKEN`); без него — ссылками.
- Kwork и FL.ru — только ссылками (автосбора нет по правилам площадок).
- Если отправка карточки не удалась (Telegram недоступен), карточка не переотправляется (R-06).
- DNS rebinding для «своего» провайдера закрыт не полностью — пиннинг IP в v1.1.
- Mini App, дайджест, `/favorites` — v1.1.
