# Охотник за вакансиями

Telegram-бот, который ищет стажировки, вакансии и фриланс-заказы под твой профиль, оценивает их релевантность **твоим собственным AI-ключом** и пишет черновик отклика. Отклики бот никуда не отправляет — только готовит текст.

```
Хабр Карьера · 78/100
Python-разработчик (стажёр) — ООО «Пример»
Зарплата: 60 000–80 000 ₽ · удалённо / Москва
Почему: стек Python + FastAPI совпадает, уровень стажёр, есть удалёнка.
https://career.habr.com/vacancies/...
[Подробнее] [Черновик отклика]
[Скрыть]    [В избранное]
```

## Возможности

- **Онбординг в чате:** согласие на обработку данных, профиль (что ищешь, стек, уровень, формат, город, зарплата, «о себе»), фильтры по умолчанию из профиля.
- **Источники:** RSS Хабр Карьеры (автоматически), официальный API hh.ru (если есть токен приложения), любая ссылка на hh.ru, Хабр Карьеру, Kwork или FL.ru, которую пришлёт пользователь.
- **Фильтры до AI:** исключения, зарплата, формат, город, ключевые слова — нерелевантное отсекается без трат токенов.
- **Свой ключ (BYOK):** пользователь подключает OpenAI-совместимого провайдера — YandexGPT, OpenRouter, Groq или любой свой. Сервис ничего не платит за LLM.
- **Работает и без AI:** оценка по ключевым словам, стеку и уровню.
- **Черновик отклика** по профилю и тексту вакансии.
- **Дедупликация:** одна вакансия — одна карточка, даже если пришла из разных запросов.
- `/delete_me` — удаление всех данных пользователя.

## Архитектура

```
app/
  core/       чистая логика: фильтры, оценка, промпты, карточки, шифрование, rate limit
  llm/        OpenAI-совместимый клиент и пресеты провайдеров
  sources/    Хабр RSS, hh.ru API, чтение страницы по ссылке (с robots.txt)
  services/   бизнес-операции с БД — общий слой для бота, API и будущего MCP-коннектора
  bot/        aiogram 3: диалоги, кнопки, middleware, планировщик сбора
  api.py      FastAPI: /health
  main.py     бот + планировщик + API в одном процессе
```

Стек: Python 3.12, aiogram 3, FastAPI, SQLAlchemy 2 (async), PostgreSQL, httpx, Docker.

```
Хабр RSS / hh.ru API ──► ingest (дедуп) ──► фильтры ──► AI-ключ пользователя ──► карточка в Telegram
                                                     └► оценка без AI (нет ключа / лимит / ошибка)
```

## Безопасность

- **AI-ключи пользователей** хранятся только в зашифрованном виде (Fernet, мастер-ключ в переменной окружения), расшифровываются на время запроса, сообщение с ключом бот сразу удаляет из чата, в логи и ответы ключ не попадает.
- **Промпт-инъекции:** текст вакансии передаётся модели только как данные внутри тегов, которые нельзя закрыть изнутри; от модели принимается только JSON-оценка или текст черновика.
- **SSRF:** адрес «своего» провайдера — только https на публичный хост.
- Весь внешний текст экранируется перед отправкой в Telegram.
- Изоляция пользователей: кнопки проверяют, что предложение принадлежит нажавшему.
- Rate limit — 20 действий в минуту на пользователя.
- Сбор только легальными путями: официальный API, публичный RSS, страницы, разрешённые robots.txt. Парсинга выдачи hh.ru, Kwork и FL.ru нет.

## Запуск

```bash
cp .env.example .env    # заполни BOT_TOKEN, MASTER_KEY, POSTGRES_PASSWORD
docker compose up -d --build
docker compose logs -f bot
```

Сгенерировать `MASTER_KEY`:

```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

Локально без Docker (SQLite):

```bash
python -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"
python -m app.main
```

## Как подключить AI-ключ

В боте: `/ai` → провайдер → модель → ключ.

| Провайдер | Где взять ключ | Заметки |
| --- | --- | --- |
| YandexGPT | Yandex AI Studio | Работает из РФ. Модель: `gpt://<folder_id>/yandexgpt-lite/latest` |
| OpenRouter | openrouter.ai/keys | Есть бесплатные модели с суффиксом `:free` |
| Groq | console.groq.com/keys | Бесплатный тариф; доступность из РФ не гарантирована |
| Свой | — | Любой OpenAI-совместимый API |

Ключ проверяется тестовым запросом с сервера. Если провайдер недоступен из страны сервера, бот так и скажет.

## Тесты

```bash
ruff check app tests
pytest -q --cov=app          # 150+ тестов, без сети и без реального LLM
bandit -q -r app -ll
```

Сквозные сценарии бота (`tests/test_bot_flow.py`) прогоняют апдейты через настоящий диспетчер aiogram с подменённым Telegram API.

## Данные и приватность

Храним Telegram ID и username, профиль, фильтры, отметки по вакансиям, AI-ключ (зашифрованным). Профиль и текст вакансии уходят только выбранному пользователем AI-провайдеру. Согласие запрашивается при `/start`, удаление — `/delete_me`. Предложения старше 90 дней (кроме избранного) удаляются автоматически.
